## 🏛️ Executive Overview

**SAMVAD 360** is the official digital public infrastructure and student governance portal of the **KL University Student Council**. Designed around the prestige, institutional heritage, and energetic student leadership of KL University, it provides students with a single, transparent gateway to discover, initiate, and track university procedures with guaranteed Turnaround SLAs.

## 🚀 Core Modules & Features

### 1. 🌟 Homepage Experience
- **Institutional Navigation**: Official crest, university accreditation badge, quick search, role indicator, and Single Sign-On launcher.
- **Hero Section**: Architectural pattern background in Dark Maroon, gold accents, official tagline, live search bar with real-time process recommendation, and quick KPI badges (98.4% SLA, 18,000+ Students, 6 Domains).
- **Frequently Accessed Services**: 1-click launch for high-demand services including:
  - On-Duty (OD) Attendance Approval
  - Hall Ticket Clearance
  - Bonafide & Study Certificate
  - Hostel Outing & Leave Pass
  - Club Event Hosting & Budget Requisition
  - SAMVAD Grievance Redressal
  - Exam Script Re-evaluation
  - Merit Scholarship Renewal
- **Explore Processes by Category**: Filterable directory across Academics, SAC & Clubs, Registrar, Hostels, and Ombudsman.
- **How SAMVAD 360 Works**: 4-step governance pipeline (Discover -> Submit Requisition -> Multi-Tier ERP Routing -> Cryptographic Issuance).
- **Official Information Directory**: Dean of Student Affairs, Director (SAC), Controller of Examinations (CoE), Registrar, Dean (Academics), Anti-Ragging & Women's Forum.
- **Latest Verified Updates**: Official university circulars and Council communiqués with digital registry authentication and letterhead viewer.
- **UN SDG 16 Institutional Commitment**: Showcase on Peace, Justice & Strong Institutions, 72-Hour Grievance SLA guarantee, and zero retaliation pledge.

### 2. 🎭 Student Activity Center (SAC) & Student Council
- Dedicated showcase of **6 Core Verticals**:
  1. *Technology & Innovation* (Focus Club, KLU Robotics, Cyber Knights, AI Spectrum)
  2. *Arts & Culture* (Swara Musical Society, Narthana Dance Troupe, Vyuha Dramatics)
  3. *Sports & Athletics* (KL Strikers, KL Hoopers, KL Shuttle Club)
  4. *Social Welfare & Outreach* (NSS, Youth Red Cross, Prakruthi Eco Club)
  5. *Literary, Oratory & MUN* (KL Model UN, Toastmasters, Samvaad Literary Guild)
  6. *Entrepreneurship & Startups* (KL E-Cell TBI, Product Crafters)
- **Flagship Event Calendar**: Samskruthi 2026, KL Hackathon 4.0, Surabhi Sports League.
- **Interactive RSVP Modal**: Issues verified digital delegate passes.
- **Council Executive Roster**: Leadership quotes and profiles of Council President, General Secretary, Academic Secretary, and Student Ombudsman.

### 3. 📋 Interactive Process Workflow & Request Simulator
- Click any procedure to open the **Process Detail Modal**:
  - Purpose & Scope
  - Prerequisites checklist
  - Required supporting documents
  - Multi-tier governance workflow steps
  - Responsible authority & physical room location
- **Digital Request Initiation**: Students can submit an official request, choose attachments, and receive an authentic tracking token (e.g., `KLU-PROC-2026-XXXX`) added to their live dashboard!

### 4. ⚖️ SAMVAD Grievance Redressal (Voice of KL)
- Direct confidential escalation channel to the Student Ombudsman.
- Optional **Anonymous Submission Mode** (cryptographically masked identity).
- Strict 72-Hour SLA turnaround policy.

### 5. 📊 Dual Dashboard Design
- **Student Dashboard**:
  - Deep maroon sidebar with gold highlights
  - Student profile (`2300031900` — K. Varun Teja)
  - Live table of initiated applications with status badges (`Approved`, `In Progress`, `Under Review`)
  - Joined SAC clubs & event passes
  - Direct request launch button
- **Administrative / Council Console**:
  - Dedicated role for Council Officers and Deans (`KLEF-ADM-880`)
  - Real-time KPI cards (Pending Petitions, 28.4h Average SLA Turnaround, 97.8% Compliance)
  - Actionable queue with `Approve` and `Escalate to Dean` buttons that update in real-time
  - Departmental turnaround efficiency charts

## 🛠️ Development & Build

### Requirements
- Node.js >= 18
- npm >= 9

### Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build Production Bundle
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```
